この記事の前提
2026年9月10日時点のReclaim.ai公式Help Centerを主に参照しています。Claude側の契約・機能提供状況はアカウントによって異なる場合があります。

Claude × Reclaim.ai連携とは？

Reclaim.aiはMCP（Model Context Protocol）を介してClaudeと接続できます。公式ガイドでは、Claude Code、Claude Desktop、Claude Webが対象として案内されています。

Claude単体でカレンダーを直接「賢くする」というより、Claudeを会話インターフェースにし、Reclaimが持つカレンダー・優先度・会議負荷などのスケジューリング文脈へ接続するイメージです。

必要なもの

  • Claudeアカウント（利用するクライアントでMCP / Connectorにアクセスできること）
  • Reclaim.aiアカウント
  • Reclaimへ接続したGoogle CalendarまたはMicrosoft Outlook Calendar
  • Claude Codeを使う場合はローカルにClaude Codeがインストールされていること

Claude Codeで接続する

Reclaim公式ガイドでは、Claude CodeのターミナルでReclaim MCPサーバーを追加し、その後プラグイン画面から認証する流れが案内されています。

claude mcp add Reclaim -t http https://mcp.reclaim.ai

追加後、Claude Codeを再起動し、/pluginからInstalledタブへ進んでReclaimを選択。ブラウザ認証でReclaimへのアクセスを許可します。接続確認にはclaude mcp listが案内されています。

Claude Desktop / Webで接続する

Claude DesktopまたはWebでは、Settings → Customize → Connections → Add Custom Connectorへ進み、ReclaimのMCPサーバーURLを追加する手順が公式に掲載されています。

https://mcp.reclaim.ai

登録後にブラウザでReclaimアカウントを認証し、Claude側で必要な権限を許可します。

何ができる？

Reclaim公式は、Claudeからスケジューリングを自然言語で管理できると説明しています。実用上は、空き時間・予定・優先度・会議負荷を踏まえて、集中時間の確保や予定調整をAIとの会話から進める用途が中心です。

  • 「今週の集中時間を確認して」
  • 「木曜までに2時間の作業枠を確保したい」
  • 「会議が詰まりすぎている日を見つけて」
  • 「予定変更案を作って、反映前に見せて」

上記は使い方のイメージです。実際に利用できるツールや操作は、Reclaim・Claude側で許可されている機能と権限に依存します。

勝手に予定が変わる？

Reclaim 2.0ではPlanner / Preview Modeが用意され、変更を本番カレンダーへ反映する前に確認できる設計が案内されています。AIに予定を任せる場合でも、いきなり全変更を自動確定させるより、Previewを挟んで確認する運用が安全です。

この連携が向いている人

  • Claudeを普段から仕事や学習の中心に使っている人
  • Google Calendar / Outlookの予定調整に時間を取られている人
  • AIに「回答」だけでなく実際のスケジュール設計まで任せたい人
  • MCPを使って複数ツールをつなぐワークフローを試したい人
